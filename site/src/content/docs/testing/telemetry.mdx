---
title: OpenTelemetry
description: Spans for every request, turn, tool call and permission question, live on either side of a connection or from a saved trace.
---

`otelTap()` turns an ACP connection's messages into OpenTelemetry spans. It works on a client and on an agent, and `spansFromTrace()` makes the same spans from a saved trace.

```ts
import * as otel from '@opentelemetry/api';
import { AcpClient, otelTap } from '@deft-subspace/acp';

const telemetry = otelTap(otel, { attributes: { 'acp.agent': 'claude' } });
const client = await AcpClient.connect(channel, { tap: telemetry });
// ... when the connection is closed:
telemetry.close();
```

On an agent, pass it to the peer: `serveAgent(channel, { ..., peer: { tap: telemetry } })`. With `start()`, pass `tap: telemetry`; it works alongside `trace`.

Subspace has no OpenTelemetry dependency: you pass the `@opentelemetry/api` module. Without a registered SDK, its tracer does nothing, so the tap costs next to nothing when tracing is off.

## The spans

| Span | Kind | What it covers |
|---|---|---|
| Every request, named by its method (`initialize`, `session/new`, `fs/read_text_file`, ...) | `CLIENT` if this side sent it, `SERVER` if it received it | From the request to its answer. `rpc.system`, `rpc.method`, `rpc.jsonrpc.request_id`; on an error, `rpc.jsonrpc.error_code` and `rpc.jsonrpc.error_message`, and the span is an error. |
| `session/prompt` | as above | The turn: it ends when the turn does (v1: the answer; v2: the answer and the idle state). `acp.stop_reason`, `acp.session_id`, `acp.usage.used` and `acp.usage.size`; events for `session/cancel`, `cancel requested` and each `plan`. |
| `tool_call` | `INTERNAL` | Inside its turn, from the first update to `completed` or `failed` (an error). `acp.tool_call.id`, `acp.tool_call.kind`, `acp.tool_call.status`. |
| Requests about a session during a turn | as above | Inside the turn: permission questions (`acp.permission.outcome`, `acp.permission.option_id`), file and terminal requests, form questions. |

`initialize` also records `acp.protocol_version`, `acp.agent.name` and `acp.agent.version`.

- **Nesting:** a request starts under the context that is active when it is sent. Call `session.prompt()` inside your own span (for example an HTTP request's) and the turn, with everything inside it, belongs to that trace.
- **Privacy:** nothing from the conversation is recorded: no prompt or message text, and no tool titles, which can hold commands and paths. `otelTap(otel, { titles: true })` adds `acp.tool_call.title`.
- **Unfinished work:** a tool call still open when its turn ends is ended with it and marked `acp.unfinished` (and `acp.tool_call.background` when the agent reported it as background work). `close()` ends everything else still open the same way.

## From a saved trace

```ts
import { parseTrace } from '@deft-subspace/kernel';
import { spansFromTrace } from '@deft-subspace/acp';

spansFromTrace(parseTrace(await readFile('run.jsonl', 'utf8')), otel);
```

The spans get the times the trace recorded. Use this for scenario failure bundles, the recorded corpus, or any run made with `trace` but without OpenTelemetry set up.
