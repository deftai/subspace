```ts
import { tool } from '@deft-subspace/acp';
import { z } from 'zod';

const listFiles = tool({
  description: 'List the files in a folder',
  input: { type: 'object', properties: { path: { type: 'string' } }, required: ['path'] },
  schema: z.object({ path: z.string() }), // optional: checks the input and types it
  kind: 'read',                            // how clients show it, and how permission rules match it
  title: ({ path }) => `List ${path}`,     // what the client shows for a call
  run: ({ path }, { signal }) => readdir(path),
});
```

<TabItem label="Python">

```python
import os

from deft_subspace.acp import tool
from pydantic import BaseModel


class ListFiles(BaseModel):
    path: str


list_files = tool(
    description="List the files in a folder",
    input={"type": "object", "properties": {"path": {"type": "string"}}, "required": ["path"]},
    schema=ListFiles,                        # optional: checks the input and makes it a ListFiles
    kind="read",                             # how clients show it, and how permission rules match it
    title=lambda args: f"List {args.path}",  # what the client shows for a call
    run=lambda args, ctx: os.listdir(args.path),
)
```

- `input` is the JSON Schema the model or MCP client sees. With a validator that can produce JSON Schema itself, it may be left out.
- `ask: true` (or a question) asks the user before each call.
- Output: a string is used as it is; anything else becomes JSON.

## Three ways to use it

- **A model-backed agent** offers it to the model: `modelAgent({ model, tools: { listFiles } })`. See [Agents backed by a model](../model-agents/).
- **Any agent** runs it as a step: `await turn.useTool(listFiles, { path: 'src' })`. It is checked, shown with its title and kind, asked about if it says so, and its output is shown in the tool call.
- **A client** serves a set to the agent over the ACP connection, with no MCP handler to write:

<Example file="editor-tools.ts" ts={editorTools} py={editorToolsPy} />

`client.serveTools({ name, tools })` answers MCP discovery, `tools/list` and `tools/call` (checking the input; a failing tool is an `isError` result), and marks read kinds read-only. The agent must take the `acp` MCP transport; see [MCP-over-ACP](../../mcp/over-acp/).
