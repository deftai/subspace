`serveStdio(options)` (from `./node`) serves the agent on stdin and stdout, and sends `console.log` to stderr so a stray log line cannot corrupt the protocol. Use `serveAgent(channel, options)` for any other channel.

The library answers `initialize`, `session/new`, `session/prompt`, `session/cancel` and `session/close`, and calls your `prompt` handler once per turn. Return a stop reason (default `end_turn`), or `'cancelled'` once `turn.signal` fires.

## What the library does for you

- **Both protocol versions.** v1 creates tool calls with `tool_call`; v2 upserts every change. v1 answers the prompt request; v2 sends `running` and `idle` state updates. Your handler is the same.
- **Cancellation.** `session/cancel` fires `turn.signal`, and tool calls still open are then marked failed.
- **Unknown sessions** get `-32002`, never a silently created session.
- **Prompts during a turn** are refused, or queued in order with `queuePrompts`.

## The turn

| Call | Does |
|---|---|
| `say(text)`, `think(text)` | Stream agent text, or thoughts. |
| `tool(init, run)` | One step: show the tool call, ask first if `ask` is set, run `run`, complete it with the result (a string becomes text) or fail it if `run` throws. A refusal throws `PermissionDenied`; let it escape and the turn ends normally. |
| `toolCall({ title, kind, status, rawInput })` | Show a tool call yourself; the handle has `update`, `complete`, `fail`, `cancelled`, `detach` and `signal`. |
| `requestPermission({ title, toolCallId })` | Ask the user; `allowed` is false for rejections and when the turn was cancelled. |
| `elicit({ message, requestedSchema })` | Ask the user a question through the client. |
| `plan(entries)` | Show a plan. |
| `showTerminal({ command, cwd })` | v2: show a terminal you run. See [Agent terminals](../../background/terminals/). |
| `mcp(name)` | Use one of the session's MCP servers: `acp` ones the client serves, and `stdio`, `http` or `sse` ones with an `mcpConnector`. See [MCP servers](../../mcp/servers/#on-the-agent-side). |
| `readFile`, `writeFile`, `terminal` | v1: use the client's files and terminals, when it offers them (`turn.clientSupports`). |
| `request(method, params)` | Call the client directly; aborted with the turn. |

## Options

- `newSession`, `loadSession` and `closeSession` hooks. `loadSession` gets a `replay` writer for history, and providing it advertises loading and resuming.
- `protocols`: the versions to accept (default both).
- `mcpTransports`: the MCP server transports you take. `acp` is handled for you. For the others, pass `mcpConnector: mcpConnector()` (from `./node`) and `turn.mcp(name)` connects; its transports are then advertised by default.
- `capabilities`: extra fields for `initialize`.
- `extensions`: typed vendor methods. See [Extensions](../extensions/).
