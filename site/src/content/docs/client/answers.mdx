## JSON answers

`json(prompt, { schema, shape, retries })` asks for JSON only, finds it in the reply (the whole reply, a code fence, or the first object or array), checks it, and if it does not fit asks once more, saying what was wrong. It throws `JsonAnswerError` (with the reply and the problems) if it never fits.

- `schema`: any [Standard Schema](https://standardschema.dev) validator (zod, valibot, arktype, ...); it also types the result.
- `shape`: what the JSON should look like, told to the agent: a description, an example, or a JSON Schema.

## Files and images

<Tabs syncKey="language">
<TabItem label="TypeScript">

```ts
import { file, image } from '@deft-subspace/acp/node';
await agent.run(['Review this change', file('src/parse.ts'), image('screenshot.png')]);
```

</TabItem>
<TabItem label="Python">

```python
from deft_subspace.acp import file, image

await agent.run(["Review this change", file("src/parse.py"), image("screenshot.png")])
```

</TabItem>
</Tabs>

`file()` embeds a text file. An agent that cannot take embedded files gets it as text instead (its path, then its contents) rather than an error. `image()` needs an agent that takes images.

## Stopping a turn

Every prompt takes `signal` (an `AbortSignal`: aborting it cancels the turn) and `timeoutMs` (cancel after this long; the timer keeps Node running until it fires, so a script with nothing else pending still gets its timeout). Stopping a `stream()` early cancels its turn too.
