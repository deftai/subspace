## Known agents

| Name | Starts | Mode it switches to |
|---|---|---|
| `claude` | `npx -y @agentclientprotocol/claude-agent-acp@<registry version>` | `default` (asks first) |
| `codex` | `npx -y @agentclientprotocol/codex-acp@<registry version>` | `read-only` (asks first; acts once allowed) |
| `grok` | `grok --permission-mode default agent stdio` | (asks first through its flag) |
| `gemini` | `npx -y @google/gemini-cli@<registry version> --acp` | |
| `opencode` | `opencode acp` | |

Any [ACP registry](/subspace/client/agents-file/) id works too, and so do agents of your own in `agents.toml` or a project's `subspace.toml`. [Known agents and agents files](/subspace/client/agents-file/) covers those, and the quirks behind each mode. Or pass `{ command, args, mode }`. Adapters run through `npx`, so the first start may take a while to download them.

## What `start()` does for you

- **Asks-first modes.** In their starting modes Claude and Codex write and run without asking, so your permission answers would never be consulted. `start()` switches them; `mode` picks another, and `mode: false` keeps the agent's own. A mode the agent does not offer is a warning (`agent.modeWarning`), not a failure.
- **One folder.** `cwd` (default `process.cwd()`) is the agent's working directory, the workspace its file requests are confined to, and the session's cwd.
- **A session, ready.** `agent.session`, `agent.run(prompt, handlers)` and `agent.prompt(prompt, handlers)`; `agent.newSession()` opens more, in the same mode.
- **Login when needed.** If opening the session fails because the agent needs a login and it offers exactly one method it handles itself, that method is used, once.
- **Questions.** Form questions from the agent are advertised; a turn's `onQuestion` answers them, and without one they are declined.
- **Clean exits.** Ctrl-C cancels the running turn and stops the agent's process group (on Windows, its own process) before exiting (`handleSignals: false` to opt out). `agent.close()`, or `await using agent = await start(...)` on Node 24 and later.

## Permissions are required

`start()` throws unless you say how to answer permission questions: `onPermission: (request) => ...`, or a fixed `permissions: 'allow'` or `'reject'`. Agents ask before writing files and running commands, and a silent refusal is the most confusing first experience there is.

## `run()`

`run(agent, prompt, options)` is `start()`, one `run()`, and `close()`. It takes the same options, plus `limits`.

## A connection you already have

`connectSession(channel, options)` is `start()` for any channel: a socket, a pipe, an in-process agent. It connects, opens a ready session (logging in once if needed, switching to `mode` if offered), and gives the same `run`, `prompt` and `close`. It needs a permission answer too, and `cwd` defaults to `process.cwd()` where there is one.

<Tabs syncKey="language">
<TabItem label="TypeScript">

```ts
import { connectSession } from '@deft-subspace/acp';

const { run, close } = await connectSession(channel, {
  cwd: '/work',
  onPermission: (request) => (request.toolCall?.kind === 'read' ? 'allow' : 'reject'),
  onMessage: (delta, { separator }) => process.stdout.write(separator + delta),
});
await run('What does this repo do?');
await close();
```

<TabItem label="Python">

```python
from deft_subspace.acp import connect_session

connected = await connect_session(
    channel,
    cwd="/work",
    on_permission=lambda request, _signal: "allow" if request.tool_call and request.tool_call.kind == "read" else "reject",
    on_message=lambda delta, info, _event: print(info.separator + delta, end=""),
)
await connected.run("What does this repo do?")
await connected.close()
```

## Which entry point do I want

| You have | Use | From | You get |
|---|---|---|---|
| An agent name (`claude`, a registry id, one in `agents.toml`) or a command, in Node | `start(agent, options)` | `@deft-subspace/acp/node` | The program started and connected, a session open in its ask-first mode, files confined to `cwd`, Ctrl-C handled; `run`, `prompt`, `close`. Needs a permission answer. |
| The same, for one prompt | `run(agent, prompt, options)` | `@deft-subspace/acp/node` | `start()`, one turn, `close()`; resolves with the `TurnResult`. |
| A program to start, and you want the plain client | `connectAgent(command, options)` | `@deft-subspace/acp/node` | `{ client, process, close }` after `initialize`. No session, no mode switch, no catalog; permissions are rejected unless you set them. |
| A channel already (a socket, a pipe, an in-process agent, a browser) | `connectSession(channel, options)` | `@deft-subspace/acp` | `start()` without the process: connected, a session open (one login retry, the mode switched if offered), `run`, `prompt`, `close`. Needs a permission answer. |
| An `AcpClient` already, and want a session the way `start()` opens one | `openSession(client, setup)` | `@deft-subspace/acp` | `{ session, modeWarning }`: `session/new`, the one-method login retry, and the mode switch. |
| A channel, and you want every choice yourself | `AcpClient.connect(channel, options)` | `@deft-subspace/acp` | The client after `initialize`. Sessions, handlers, files and terminals are up to you. |

## Seeing what happened, and errors that help

- `trace: 'run.jsonl'` records the whole connection; open it with `deft-subspace-trace run.jsonl` (or `subspace trace run.jsonl`) to see every request, answer, tool call and permission, with timing.
- Without `trace`, setting `SUBSPACE_TRACE=<folder>` traces every `start()` in the program, one file per connection, with no code change: `SUBSPACE_TRACE=traces node app.js`.
- A missing program says how to install it; an agent that needs a login says how to log in (`codex login`, ...); a slow first start through `npx` says it is downloading the adapter (`quiet: true` to silence notices).

## Options

Everything `connectAgent` takes (timeouts, `env`, `onStderr`, ...), plus `extraArgs` (after the preset's), `mode`, `session: { mcpServers, additionalDirectories }`, `files: false` to serve no files, and any [handler](../handlers/) as a default for every turn.
