An agent can ask the user a question through the client (`elicitation/create`): a **form** described by a JSON Schema, or a **URL** to open (for example, to authorize something).

<Example file="elicitation.ts" ts={elicitation} py={elicitationPy} />

- Without an `elicitation` handler, the client advertises none, and agents should not ask.
- `elicitationModes` limits what is advertised (default both). Requests in other modes are declined without calling your handler.
- An accepted form answer is checked against the agent's `requestedSchema` (`validateElicitation`: required and unknown fields, types, lengths, ranges, formats, allowed choices). One that does not fit is sent as a decline.
- A cancelled turn answers its open questions `cancel`.
- For URL mode, `onElicitationComplete` tells you when the agent says the user finished.
