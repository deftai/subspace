| Recipe | What it shows |
|---|---|
| [Review the staged diff](review/) | `json()` with a schema: findings as typed data, and an exit code for CI |

| [An agent backed by Claude](../agents/model-agents/) | `modelAgent()` and `claude()` |

To start a project of your own: `npx create-subspace my-app --template script|agent|claude-agent` (see [Getting started](../getting-started/#start-a-project)).
