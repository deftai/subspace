---
title: The subspace command
description: Run, chat with, list, check and trace ACP agents from the command line.
---

`@deft-subspace/cli` installs a `subspace` command:

```sh
subspace run claude "Summarize README.md"         # one prompt, rendered as it streams
subspace chat codex                               # turn after turn; Ctrl-C cancels a turn, again to quit
subspace agents                                   # the known agents, and whether they are installed
subspace check grok                               # the conformance checks (known quirks waived; --strict to not)
subspace test scenarios/*.json --junit results.xml # scenario files: expectations, snapshots, CI reports
subspace trace run.jsonl                          # an HTML viewer for a trace (--summary for text)
subspace run "hello" -- node my-agent.js          # any agent: its command after --
```

## Permissions

By default reads are allowed without asking, and everything else is asked about in the terminal (refused when there is no terminal). `--yes` allows everything; `--read-only` allows reads and refuses the rest.

## Options for run and chat

| Option | Does |
|---|---|
| `--cwd <dir>` | the agent's folder (default: here) |
| `--mode <mode>` | a session mode (default: the agent's ask-first mode); `--mode none` keeps its own |
| `--trace <file>` | record the connection |
| `--json` | `run`: print the result as JSON instead of rendering it |
| `--quiet` | no thoughts, tool lines or notices |

`run` exits 0 when the turn completed, 3 when the agent stopped after a refusal, 130 when it was cancelled or hit a limit, and 1 on an error.

`check` takes `--only <ids>` and `--mode`, like `check-agent.ts`.
