Subspace is an experiment. The packages are versioned `0.0.0-experiment`, live on the `experiment/deft-subspace-prototype` branch, and are not published yet. The API may change.

[`EXPERIMENT.md`](https://github.com/deftai/subspace/blob/experiment/deft-subspace-prototype/EXPERIMENT.md) records what is built, how it was checked against real agents, and what is next. The original `@deft/*` prototype packages from `main` are in `legacy/`.

## Other languages

This site is laid out for more than one language. Guides describe behaviour once, with code in tabs per language; each language's API reference is generated by its own tool; and the [conformance checks](../behaviour/conformance/) and recorded traces are language-neutral. Only TypeScript exists today.
