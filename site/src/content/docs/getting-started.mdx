## Packages

| Package | What it is |
|---|---|
| `@deft-subspace/acp` | The ACP client (`AcpClient`) and agent (`serveAgent`). `@deft-subspace/acp/node` adds starting agent programs, and file and terminal access confined to a workspace. |
| `@deft-subspace/kernel` | Channels, NDJSON framing, and a JSON-RPC peer with timeouts and cancellation. No ACP in it; written for Node, Bun, Deno and browsers (CI tests it on Node). |
| `@deft-subspace/acp-testkit` | Recording and replay of traces, fault injection, and conformance checks for agents and clients. |
| `@deft-subspace/devtools` | A trace analyzer and a standalone HTML trace viewer. |

Subspace builds on the official [`@agentclientprotocol/sdk`](https://www.npmjs.com/package/@agentclientprotocol/sdk) for its types, and adds the behaviour on top: turns, cancellation, permissions, one model for both protocol versions, and the testkit.

## Install

The packages are not on npm yet. Use them from a checkout:

```sh
git clone https://github.com/deftai/subspace && cd subspace
git checkout experiment/deft-subspace-prototype
pnpm install && pnpm test
```

From another project, link them (pnpm shown), and run `pnpm run build` in Subspace after pulling so the linked `dist/` is current:

```json
"dependencies": {
  "@deft-subspace/acp": "link:../subspace/packages/acp",
  "@deft-subspace/kernel": "link:../subspace/packages/kernel"
}
```

Inside the repository, examples and tests run the TypeScript sources directly: `node --conditions=subspace-source file.ts` (Node 22.19 or later).

## Python

The Python port is in [`python/`](https://github.com/deftai/subspace/tree/main/python): `deft_subspace.kernel` and `deft_subspace.acp`, on `asyncio`, Python 3.11 or later. The examples on this site have a Python tab where the port can express them. The testkit, devtools, CLI and the Claude model adapter are not ported yet.

The packages are not on PyPI yet. Use them from a checkout, with [uv](https://docs.astral.sh/uv/):

```sh
cd subspace/python
uv sync
uv run python examples/in_process.py
```

The names are snake_case (`new_session`, `on_permission`), options are keyword arguments, and events are frozen dataclasses. Await a turn for its result, or iterate it with `async for`. Without an event loop, `deft_subspace.acp.sync.run()` blocks until the turn ends:

```python
from deft_subspace.acp.sync import run

print(run("codex", "What does this repo do?", permissions="reject").text)
```

The [Python README](https://github.com/deftai/subspace/blob/main/python/README.md) lists every difference from the TypeScript packages.

## Start a project

```sh
npx create-subspace my-app                            # a script that uses an agent
npx create-subspace my-agent --template agent         # an agent of your own
npx create-subspace my-agent --template claude-agent  # an agent backed by Claude
```

The packages are not on npm yet: until they are, add `--subspace <path to a checkout>` to link a local one. Or skip code entirely: `subspace run claude "..."` (see [The subspace command](../cli/)).

## Three layers

- **`run()` and `start()`** (`@deft-subspace/acp/node`): known agents, sensible defaults, handlers.
- **Handler options** on any turn: `session.prompt(text, { onMessage, onToolCall, onPermission })`. See [Handlers](../client/handlers/).
- **The model underneath**: `AcpClient`, `Session`, `Turn` (async-iterable events and a result), for full control. The rest of these pages.

Every example on this site is a file in [`examples/`](https://github.com/deftai/subspace/tree/experiment/deft-subspace-prototype/examples). All of them are typechecked, and those that need no outside agent run as part of `pnpm test`, so the code here keeps working. The Python ones are in [`python/examples/`](https://github.com/deftai/subspace/tree/main/python/examples), checked with pyright and run by `examples/run_examples.py` in the same way.
